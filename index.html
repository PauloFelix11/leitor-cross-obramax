OBRAMAX

Leitor de código de posicionamento

Aponte a câmera para o código de barras ou QR Code que identifica a posição do cross.

Toque em “Ativar câmera” para começar.

Quando o código for reconhecido, ele será enviado de volta ao aplicativo de abastecimento. Se a câmera não abrir, confira a permissão de câmera do navegador.
